## 1. Project Title and Introduction
The project, **"Top News & Short Video Platform"**, is a modern, high-performance web application designed to deliver real-time news articles and short video content. The platform is optimized for Search Engine Optimization (SEO) with support for multilingual content, localized slugs, and dynamic routing. It consists of three key components:
1. **RESTful Backend API:** Powering the application with Express.js, Node.js, and MongoDB.
2. **User Portal (Frontend):** A responsive, fast, and visually rich interface built using React, Vite, and Tailwind CSS.
3. **Admin Dashboard:** A content management panel for editors to publish, edit, and delete news articles and short videos.

## 2. Objectives
* To build a scalable and responsive news website that supports multi-category filtering (World, Business, Technology, Sports, Health, Opinion, etc.).
* To implement a short video feature similar to modern social feeds (Reels/Shorts) tailored for news consumption.
* To achieve excellent SEO performance using localized, transliterated slugs for non-English languages (Hindi, Gujarati, Bengali, etc.).
* To provide an administrative panel with secure media upload capabilities (Cloudinary integration) for easy content management.

## 3. Technology Stack
* **Frontend:** React.js, Vite, Tailwind CSS, TypeScript, Lucide Icons, Shadcn UI
* **Backend:** Node.js, Express.js
* **Database:** MongoDB (using Mongoose ODM)
* **Media Storage:** Cloudinary API for image and video assets
* **State Management:** Zustand / React Context

## 4. Scope of Work & Deliverables
* **Database Design:** Design schemas for News Articles and Short Videos, incorporating indexing on frequently filtered fields (language, category, views).
* **API Endpoints:** Build endpoints for fetching paginated articles and videos by language, category, and section (main body, sidebar, widget).
* **Multilingual Slug Engine:** Create utility algorithms to transliterate native languages (Hindi, Gujarati, etc.) into Latin characters for clean SEO URLs.
* **Frontend Development:** Implement responsive UI components (Navbar, Weather Widget, Category Feeds, Article Viewer, Video Player).
* **Admin Controls:** Build forms for content creation with image uploads and validation.
