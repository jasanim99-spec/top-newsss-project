1. PROJECT OVERVIEW & CONCEPT (પ્રોજેક્ટ પરિચય)
================================================================================
TOP NEWS is a next-generation, production-grade digital news publishing and 
short-video streaming platform. It connects public news readers, field journalists/
reporters, chief editors, and advertisers into a unified real-time system.

Key Capabilities:
1. Multi-Lingual News Engine: Serves news articles and short video clips across
   multiple languages (Gujarati, Hindi, English).
2. Short Video Reels Streamer: Custom HTML5 & YouTube Shorts video player with
   CORS-safe high-speed CDN playback.
3. Role-Based Editorial Desk: Dedicated workflows for Chief Editors ('admin') and
   Accredited Journalists ('reporter').
4. Advertisement Revenue Hub: Full banner campaign management with click counter
   analytics and client request approval workflow.
5. Web Push Broadcast: Browser notification engine using Web Push API & VAPID keys.
6. Dark & Light Theme System: Responsive UI/UX with active local persistence.
7. Mobile-First Architecture: 100% responsive dock, zero overflow layout, 4-column
   equal grids for mobile screens.

6. BACKEND EXPRESS API SERVER (top-news-backend)
================================================================================
Routes & Endpoints:

1. News Endpoints:
   - GET /news or /api/news                : List published news with filters & pagination
   - GET /news/:id or /api/news/:id        : Fetch article details by ID or slug
   - POST /news or /api/news              : Create new article
   - PUT /news/:id or /api/news/:id        : Update existing article
   - DELETE /news/:id or /api/news/:id     : Soft-delete / remove article
   - PATCH /news/:id/hero                  : Toggle homepage Hero section feature

2. Short Videos Endpoints:
   - GET /short-videos or /api/short-videos : List short videos with category & topic filters
   - GET /short-videos/:id                 : Fetch video by ID or slug
   - POST /short-videos                    : Create short video reel
   - PUT /short-videos/:id                 : Update video metadata
   - PATCH /short-videos/:id/views         : Atomically increment view count
   - DELETE /short-videos/:id              : Delete video reel

3. Advertisements Endpoints:
   - GET /ads or /api/ads                  : Fetch active display ads for website
   - POST /ads/requests                    : Client ad campaign submission
   - PATCH /ads/requests/:id/approve       : Admin approval of client ad request
   - PATCH /ads/:id/click                  : Increment ad click count

4. Reporter Leaves Endpoints:
   - GET /leaves or /api/leaves            : Fetch leave requests
   - POST /leaves                          : Submit new leave request
   - PATCH /leaves/:id/status              : Update leave status ('approved' / 'rejected')

-- 1. News Articles Table
CREATE TABLE IF NOT EXISTS news_articles (
  id VARCHAR(128) PRIMARY KEY,
  title VARCHAR(500) NOT NULL,
  slug VARCHAR(500) UNIQUE NOT NULL,
  content TEXT,
  summary TEXT,
  category VARCHAR(100),
  topic VARCHAR(100),
  language VARCHAR(20) DEFAULT 'en',
  image_url TEXT,
  author_name VARCHAR(100),
  views INTEGER DEFAULT 0,
  is_hero BOOLEAN DEFAULT false,
  status VARCHAR(20) DEFAULT 'published',
  published_at TIMESTAMPTZ DEFAULT NOW(),
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Short Videos Table
CREATE TABLE IF NOT EXISTS short_videos (
  id VARCHAR(128) PRIMARY KEY,
  title VARCHAR(500) NOT NULL,
  slug VARCHAR(500) UNIQUE NOT NULL,
  description TEXT,
  video_url TEXT NOT NULL,
  thumbnail_url TEXT,
  duration INTEGER DEFAULT 0,
  category VARCHAR(100),
  topic VARCHAR(100),
  language VARCHAR(20) DEFAULT 'en',
  section VARCHAR(50) DEFAULT 'main',
  views INTEGER DEFAULT 0,
  status VARCHAR(20) DEFAULT 'published',
  published_at TIMESTAMPTZ DEFAULT NOW(),
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. Advertisements Table
CREATE TABLE IF NOT EXISTS advertisements (
  id VARCHAR(128) PRIMARY KEY,
  title VARCHAR(255) NOT NULL,
  image_url TEXT NOT NULL,
  link_url TEXT NOT NULL,
  position VARCHAR(50) DEFAULT 'sidebar',
  click_count INTEGER DEFAULT 0,
  client_name VARCHAR(255),
  client_email VARCHAR(255),
  is_active BOOLEAN DEFAULT true,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 4. Reporter Leaves Table
CREATE TABLE IF NOT EXISTS reporter_leaves (
  id VARCHAR(128) PRIMARY KEY,
  reporter_id VARCHAR(128),
  reporter_name VARCHAR(255),
  leave_type VARCHAR(100),
  start_date VARCHAR(50),
  end_date VARCHAR(50),
  total_days INTEGER,
  backup_reporter VARCHAR(255),
  reason TEXT,
  status VARCHAR(20) DEFAULT 'pending',
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
